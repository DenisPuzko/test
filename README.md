# ⚡ Моніторинг світла (Черкаська область)

**Неофіційний вебзастосунок для зручного відстеження графіків погодинних відключень (ГПВ) у Черкаській області.**

Цей проєкт створений, щоб забезпечити мешканцям регіону швидкий та інтуїтивно зрозумілий доступ до інформації про електропостачання, поєднуючи дані офіційного API та гнучкість налаштувань через Google Sheets.

---

## ✨ Основні можливості

* **🔍 Розумний пошук адреси:** Кастомні випадаючі списки з миттєвою фільтрацією для вибору філії, міста та вулиці.
* **📱 Mobile-First Design:** Інтерфейс, оптимізований для смартфонів, з підтримкою **свайпів** для перемикання між днями тижня.
* **📊 Гнучкий графік:** Відображення 24-годинної сітки з виділенням поточної години та підтримкою станів "можливе відключення".
* **🔄 Подвійне джерело даних:** * Автоматичне визначення черги через API АТ «Черкасиобленерго».
    * Синхронізація розкладу через Google Sheets (CSV) для оперативного оновлення графіків.
* **⚖️ Правова прозорість:** Вбудований дисклеймер з посиланнями на офіційні джерела.

---

## 🛠 Технологічний стек

* **Frontend:** HTML5, CSS3 (Custom Variables, Flexbox, Grid), JavaScript (Vanilla JS).
* **API Integration:** Fetch API для отримання даних з серверів Обленерго.
* **Data Management:** Google Sheets API (CSV export) для зберігання та редагування розкладів.
* **Automation:** MutationObserver для синхронізації кастомних UI-компонентів.
